Real-time Chat

Instant messaging application with WebSocket technology

Project Overview

This real-time chat application enables instant communication between users with features like group chats, private messaging, and file sharing. Built with WebSocket technology for seamless real-time updates and a modern, responsive interface.

Key Features

  • Real-time messaging with WebSocket
  • Group chat rooms
  • Private one-on-one messaging
  • File and image sharing
  • User online/offline status
  • Message history and search
  • Typing indicators
  • Emoji support

Technologies Used

React Node.js MongoDB Express Stripe API JWT Redux Material-UI
