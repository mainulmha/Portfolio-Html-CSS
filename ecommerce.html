E-Commerce App

A full-stack e-commerce platform built with modern web technologies

Project Overview

This comprehensive e-commerce application provides a complete online shopping experience with user authentication, product management, shopping cart functionality, and secure payment processing. Built using the MERN stack for optimal performance and scalability.

Key Features

  • User registration and authentication
  • Product catalog with search and filtering
  • Shopping cart and wishlist
  • Secure payment integration (Stripe)
  • Order tracking and history
  • Admin dashboard for inventory management
  • Responsive design for all devices
  • Real-time inventory updates

Technologies Used

React Node.js MongoDB Express Stripe API JWT Redux Material-UI
