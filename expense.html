Expense Tracker

Personal finance management app with budgeting and analytics

Project Overview

This intuitive expense tracking application helps users manage their personal finances effectively. Features include expense categorization, budget setting, financial goal tracking, and detailed analytics with visual charts. Built with a clean, user-friendly interface.

Key Features

  • Add/edit/delete expenses and income
  • Category-based organization
  • Budget creation and monitoring
  • Financial goal setting
  • Interactive charts and graphs
  • Monthly/yearly reports
  • Data export functionality
  • Multi-currency support

Technologies Used

React Node.js MongoDB Express Stripe API JWT Redux Material-UI
